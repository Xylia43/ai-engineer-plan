# AI 应用工程师 · 30 天筑基学习计划

一个可直接在浏览器中使用的交互式学习计划，包含每日知识点、待办清单、每日小测和每周大测。

## 在线访问

发布后可通过 GitHub Pages 访问：

https://xylia43.github.io/ai-engineer-plan/

## 本地使用

直接用浏览器打开 `index.html`，或启动一个本地静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000/`。

## 功能

- 30 天学习内容与日期导航
- 学习、待办、每日小测、每周大测四个标签页
- 标题栏实时月历、本机时钟与实际打卡按钮；点击日期会切换到当天学习内容
- 支持今天打卡、过去日期补打卡，也支持未来日期提前打卡
- 打卡日期与实际打卡时间分开记录；补打卡显示“补”，提前打卡显示“提”
- 每日待办中的代码练习已整合进每日小测，可直接编辑代码并检查关键要求
- 提供提示、参考答案和逐项检查反馈
- 练习代码草稿、通过状态和逐项检查结果会按学习日期缓存，刷新页面或切换日期后可恢复
- 修改已检查过的代码时，旧检查结果会失效并隐藏，重新检查后再次缓存
- 每日小测和每周大测会缓存所选答案、提交状态、得分与答案解析
- 待办完成状态保存在浏览器本地
- 选择题即时判分与答案解析
- 响应式页面布局，适配桌面与手机

## 打卡记录与 GitHub 同步

GitHub Pages 是纯静态站点，不能安全地直接在网页中写入仓库。因此页面使用 GitHub 私人 Gist 保存打卡记录：

1. 点击页面标题栏中的“连接 GitHub”。
2. 创建一个只勾选 `gist` 权限的 Classic Token。
3. 输入 Token 并连接，页面会自动创建或更新当前账号的私人 Gist。
4. 之后每次打卡都会尝试自动同步，也可在“管理同步”中手动立即同步。

数据按 GitHub 账号隔离：

- 每个账号使用独立的私人 Gist，文件名固定为 `ai-engineer-plan-checkins.json`。
- 打卡记录同时保存在浏览器本地；本地记录按 GitHub 登录名分区，不同账号不会相互合并。
- 今日、补打卡和提前打卡都会同步；记录中同时保存目标日期与实际打卡日期、时间。
- 首次连接账号时，连接前产生的匿名本地记录会迁移到该账号；成功同步后会清除匿名副本，避免带到其他账号。
- Token 只保存在当前标签页的 `sessionStorage`，关闭标签页后清除；不会写入网页、仓库或 Gist。
- 断开连接只清除当前会话授权，不会删除 GitHub 中已经保存的记录。

## 本地缓存

代码练习、每日小测和每周大测的进度使用当前浏览器的 `localStorage` 缓存，按学习日期与周次区分。缓存不会上传到 GitHub，也不会在不同浏览器或设备之间同步；打卡记录则按上面的 GitHub 账号隔离规则同步到私人 Gist。

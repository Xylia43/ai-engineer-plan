## 三级/高级工计划的资料边界

策划时已核对以下资料：

1. **《人工智能训练师国家职业技能标准（2021 年版）》**：职业编码 4-04-05-05，共五个等级；三级/高级工考理论知识和技能考核，国家标准给出的参考培训学时为 40 标准学时。
2. **佛山省级特色职业培训包-人工智能训练师**：三级总学时 140，其中职业基本素质 16、职业技能 64、其他 60。
3. **嘉兴南湖区职业技能竞赛-人工智能训练师技术工作文件**：仅作实操题型参考。该文件明确以五级/初级工为主、适当增加四级内容，**不能当作三级考试范围或题库**。

页面明确区分：

- **三级官方核心**：职业道德、计算机与法律基础，以及业务分析、智能训练、智能系统设计、培训与指导四个职业功能。
- **官方主题实操**：业务流程、数据治理、模型评估、测试报告、产品优化、人机交互和培训讲义。
- **AI 应用工程师扩展**：LLM、RAG、Agent 等，只用于连接转岗目标，不冒充三级考纲。
- **自编阶段测**：用于复盘，不是官方题库。

本页不是官方教材、官方题库或报考承诺。考试题型、申报条件、费用、补贴和证书使用范围以当地人社部门及备案评价机构公告为准。“三级/高级工”不是“高级工程师”，也不等于 AI 应用工程师岗位认证。

### 申报条件提醒

国家标准给出的三级路径之一为：具有大专及以上本专业或相关专业毕业证书，并累计从事本职业或相关职业工作 3 年以上。计算机科学硕士和 Android 开发经历是否满足当地“相关专业/相关职业”口径，需要由当地备案评价机构确认，不能仅凭“CS 硕士 + 10 年开发”直接判断可以报考。

国家标准脚注举例：相关职业包括人工智能工程技术人员、呼叫中心服务员、电子商务师等；相关专业包括电工电子类、信息类等。脚注是范围示例，不等于自动认定。Android 开发岗位名称不在脚注示例中，应以当地备案评价机构的书面口径为准。

### 学习结构

- 8 周节奏，每周 3 个核心学习单元、1 个官方主题实操、1 个复盘、1 个阶段测、1 个弹性复盘日。
- 合计 24 个核心学习单元、8 个实操、8 个复盘、8 个阶段测。
- 24 个核心学习单元均配有自编每日选择题，共 50 道；另有 8 套阶段测、共 40 道。题目用于检查理解，不是官方题库。
- 8 周编排是自学节奏，不是官方培训天数或考试时长。

## 页面功能

- 月历日期选择、本机实时时钟和实际打卡按钮
- 支持今天打卡、过去日期补打卡、未来日期提前打卡
- 打卡日期与实际打卡时间分开记录；补打卡显示“补”，提前打卡显示“提”
- 点击日期切换当天学习内容，保存打卡历史
- 每日知识点、待办、自编选择题和每周阶段测
- 8 个实操作答区，带提示、参考答案和结构检查
- 官方申报口径、权重表，以及广东培训包三级技能考核参考蓝图
- 课程勾选、练习草稿、选择题答案、成绩和待办按学习日期保存在浏览器本地
- 响应式布局，适配桌面和手机

## 打卡记录与 GitHub 同步

GitHub Pages 是纯静态站点，页面通过 GitHub 私人 Gist 保存打卡记录：

1. 创建只勾选 `gist` 权限的 Classic Token。
2. 在页面标题栏点击“连接 GitHub”并输入 Token。
3. 页面会自动创建或更新当前账号的私人 Gist。
4. 之后打卡会自动同步，也可手动立即同步。

三级页面使用独立的 Gist 文件名 `ai-trainer-level3-checkins.json`，不会与 30 天计划的打卡数据混用。Token 只保存在当前标签页的 `sessionStorage`，关闭标签页后清除；不会写入网页、仓库或 Gist。

## 本地使用

```bash
python3 -m http.server 8000
```

然后访问：

- `http://localhost:8000/`
- `http://localhost:8000/ai-engineer-30day.html`
- `http://localhost:8000/ai-trainer-level3.html`

## 本地缓存

课程勾选、实操草稿、选择题答案和待办使用浏览器 `localStorage`，按学习日期或学习单元区分，不会自动跨设备同步。打卡记录按 GitHub 账号隔离并同步到私人 Gist。
